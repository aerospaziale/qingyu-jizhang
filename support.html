语音记账没有反应 / 听不到我说话？

首次使用语音功能时，系统会请求「麦克风」和「语音识别」权限，请选择允许。如果之前拒绝过，可以到 iPhone 设置 → 轻语记账 中重新打开。

录音时尽量靠近话筒、在安静环境说话；说完停顿一下，App 会自动结束录音并识别。若设备暂时无法使用语音识别，也可以直接用键盘输入记账。

自动记账怎么设置？

在 App 内打开 我的 → 自动记账，按页面上的三步教程操作：

  • 第 1 步：在「快捷指令」App 新建指令，依次添加「截屏」和「自动记账」；
  • 第 2 步：到 设置 → 操作按钮 → 快捷指令，选择刚创建的指令；
  • 第 3 步：付完钱按一下侧边按钮，截图会在本机识别并自动入账。

也可以直接用快捷指令、灵动岛或复制账单截图后触发。识别只在本机进行，截图副本在识别完成后立即删除。侧边按钮速记属于会员功能；免费用户同样可以用快捷指令或复制截图来触发自动记账。

我的账单数据会上传到云端吗？

不会。轻语记账没有账号体系，也没有云端服务器。账单、分类、预算、聊天记录和经营数据都保存在你的设备本地，我们不上传、不收集、不出售。

只有三种由 Apple 系统提供的联网行为可能发生：App Store 购买与恢复购买、添加地点时使用 Apple 地图把坐标换成店名、以及设备不支持端上语音识别时由 Apple 系统语音服务处理。除此之外，账单数据全程不经过网络。

完整说明见 隐私政策。

换手机或重装 App，数据还在吗？

数据保存在本机，卸载 App 会一并删除。换机前请在 我的 → 备份与导出 生成一份 JSON 完整备份（或加密备份），保存到「文件」App 或通过 AirDrop 发送到新设备，再在新手机上导入即可。

如果你开启了 iCloud 设备备份，App 数据也会随系统备份一起备份到你的 iCloud 账户（由 Apple 加密，我们无法访问）。

如何导入微信 / 支付宝 / 银行账单？

先在微信、支付宝或银行 App 中导出账单文件（CSV / XLSX / TXT），然后打开轻语记账，进入 我的 → 账单导入，选择文件即可。解析全程在本机完成，不上传文件。

账单导入属于会员功能；具体支持的文件格式以导入页面的说明为准。

会员怎么恢复购买 / 怎么取消订阅？

恢复购买：打开轻语记账的会员升级页，点击「恢复购买」。会员资格跟随你的 Apple ID。

取消订阅：打开 iPhone 的 设置 → Apple ID → 订阅 → 轻语记账，选择取消。取消后，当前订阅周期结束前仍可使用会员功能。终身买断为一次性付费，不自动续费。

会员功能全部在本机运行，不收集、不上传任何账单数据。详见 用户协议。

App 需要哪些权限？可以关闭吗？

只在你主动使用对应功能时请求权限：

  • 麦克风 / 语音识别：语音记账和轻聊按住说话；
  • 相机：拍摄小票、账单照片或扫描商品；
  • 相册：选择账单照片、读取你指定的截图；
  • 定位：为账单添加消费地点；
  • 面容 ID：解锁隐私保险柜、应用锁和经营锁；
  • 通知：预算提醒与记账完成提示。

所有权限都可以在系统设置中随时关闭；关闭后仅对应功能不可用，其他功能与本地数据不受影响。

支持哪些设备？

轻语记账支持 iPhone，系统要求 iOS 17 及以上。侧边按钮速记需要支持「操作按钮」的机型；灵动岛相关提示需要支持灵动岛的机型。不支持的设备仍可正常使用语音、聊天、截图自动记账等核心功能。
